# Netflix Data Science & Machine Learning Project

## Auspify Technologies — Data Science Internship

This project demonstrates six practical data science tasks using a Netflix catalogue dataset.

## Dataset
- Total records: 8,790
- Movies: 6,126
- TV Shows: 2,664

## Completed Tasks
1. Data Cleaning and Preprocessing
2. Exploratory Data Analysis
3. Recommendation System
4. Trend Prediction Analysis
5. Machine Learning Classification
6. Interactive Business Insights Dashboard

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Plotly, Google Colab and HTML.

## Machine Learning Results
- Logistic Regression Accuracy: 78.44%
- Random Forest Accuracy: 78.78%
- Best Model: Random Forest

## Project Files
- Main Jupyter Notebook (.ipynb)
- Original and cleaned datasets
- Task screenshots
- Final Project Report (PDF)

## How to Run
1. Open the notebook in Google Colab.
2. Upload Dataset.csv.
3. Run the cells in sequence.
4. Review the outputs and visualizations.

## Conclusion
This project demonstrates data cleaning, exploratory analysis, recommendation systems, trend forecasting, machine learning and business reporting.
